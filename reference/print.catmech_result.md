# Print a catmech result

Displays a compact summary of a fitted \`catmech_result\`, including the
engine, target variable, reference subset, predictors, clustering, and
convergence status.

## Usage

``` r
# S3 method for class 'catmech_result'
print(x, ...)
```

## Arguments

- x:

  A \`catmech_result\` object.

- ...:

  Additional arguments passed to print methods (currently ignored).

## Value

\`x\`, invisibly.
