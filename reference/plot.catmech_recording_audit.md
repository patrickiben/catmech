# Plot a recording audit summary

Displays disagreement rates across strata or overall error distribution.

## Usage

``` r
# S3 method for class 'catmech_recording_audit'
plot(x, y, col_points = "navy", ...)
```

## Arguments

- x:

  A \`catmech_recording_audit\` object.

- y:

  Unused.

- col_points:

  Color for stratum points (default \`"navy"\`).

- ...:

  Additional arguments passed to \[graphics::par()\].

## Value

Invisible \`NULL\`.
